## Welcome to Orbit

Orbit IT Solutions helps growing businesses use technology with confidence. This
website makes it easy for customers to discover practical IT services, choose
what they need, review an order, and contact the team remotely.

## What you can do

|                         |                                                                        |
| ----------------------- | ---------------------------------------------------------------------- |
| **Browse services**     | Explore office networking, IT support, and web development options.    |
| **Build an order**      | Add services to a cart and review the order before payment.            |
| **Pay with M-Pesa**     | Follow the on-page payment guidance and provide the confirmation code. |
| **Confirm on WhatsApp** | Send order details to the team to speed up follow-up.                  |
| **Contact the team**    | Find direct contact and location information in one place.             |

## Services

### Network maintenance

Keep your office connected with practical network setup and maintenance support.

## Run it locally

Because this is a static website, you can preview it with any local web server.
For example, with Python installed:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

> Opening `index.html` directly also works for most page content, but a local
> server provides a more reliable preview for forms and browser-based features.

## Deploy it

The website can be hosted on any static hosting service, including GitHub Pages,
Netlify, Vercel, or a traditional web server. Upload the repository contents
while preserving the existing folder structure, especially `assets/` and
`forms/`.
